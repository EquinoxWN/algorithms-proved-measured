## Shared vectors

Command: `python spec/generate_vectors.py --check` (passes: committed vectors match the generator).

| Algorithm | Cases | Expected values come from | Covers |
|---|---|---|---|
| `lower_bound` | 20 | linear scan | empty array, all-equal values, target below, between and above all values |
| `merge_sort` | 20 | selection sort | empty, single, sorted, reversed, duplicates, negatives |
| `dijkstra` | 20 | Bellman-Ford | one vertex, unreachable vertices, parallel edges, zero weights, cycles |
| `edit_distance` | 20 | plain recursion | empty strings, equal strings, `kitten` / `sitting` = 3 |
| `find_all` | 20 | naive search | empty pattern, overlapping matches, pattern longer than text |
| **Total** | **100** | | |
