## Quality control (DMAIC)

| Phase | This repository |
|---|---|
| Define | Hand-picked examples miss edge cases, and copies of one algorithm in several languages drift apart; this affects students and engineers who write algorithmic code in Java, Python or JavaScript. M1 counts when five algorithms exist in all three languages behind the same signature, pass the shared vectors generated from brute-force oracles, and match their own oracle on 500 seeded random inputs per algorithm ([RFC 0001](../rfc/0001-design.md)). |
| Measure | `python spec/generate_vectors.py --check`, `mvn verify`, `pytest` and `npm test` on an Intel Core i7-13700H with Windows 11, plus `pip-audit` and an OSV.dev check of the resolved Maven dependencies in the recheck. Each language ran 100 vector cases and 2,500 random oracle checks: 106 Java, 109 Python and 107 JavaScript tests passed (322 in all), 0 failed. |
| Analyze | Every implementation agreed with the vectors and with its oracle on all 7,500 random inputs, so no algorithm defect was found. One defect was found in the 2026-10-06 recheck: the test-scope `jackson-databind` 2.18.2 had known advisories. Growth-rate fits are not measured yet (M2). |
| Improve | `jackson-databind` was upgraded from 2.18.2 to 2.22.3; the OSV.dev check then found no advisories. |
| Control | The `ci` workflow's `build` job runs `make ci` (vector staleness check, ruff with security rules and format check, `mvn compile`, `node --check` and the three test suites) and `make audit` (`pip-audit`, and OSV-Scanner on a CycloneDX SBOM of every resolved Maven dependency, added 2026-10-07) on every push and pull request, with every action pinned to a commit SHA. In the code, `generate_vectors.py --check` fails on stale vectors, and Dijkstra rejects an out-of-range source or endpoint and negative weights in all three languages. |
